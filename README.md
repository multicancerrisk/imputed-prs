# imputed-prs

Calculate Polygenic Risk Scores via linear imputation of missing variants.

## Installation

```bash
pip install imputed-prs
```

For development:

```bash
pip install -e ".[dev]"
```

## Quick Start

```python
from imputed_prs import __version__

print(f"imputed-prs version: {__version__}")
```
